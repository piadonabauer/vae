# CVPR figure suite (v2)

Generated by `make_figures_cvpr.py`. Figures are produced at their final print
size — 3.25" (`\columnwidth`) or 6.875" (`\textwidth`) — so include them with
`width=\linewidth` / `width=\textwidth` and the fonts come out exact.
Font is STIXGeneral (Times-compatible, matches the CVPR body).

Face tiles are extracted losslessly from the images embedded in the old
`../figures/qual_*.pdf` panels (pymupdf), so faces are whole — no pixel-margin
crops. The 9-frame strip tiles come from `_wandb_E1d.png` via automatic
white-gutter detection. No |rec−GT| error maps, no mouth zooms.

| File | Size | Use |
|------|------|-----|
| `qual_ghosting.pdf` | 1-col | views × settings, PSNR under recs |
| `qual_bleeding.pdf` | 2-col (`figure*`) | GT vs 16-ch rec, all 9 frames, chunk-colored |
| `qual_bleeding_grid.pdf` | 1-col | supplement: chunk-1 frames × latent widths |
| `qual_capacity.pdf` | 1-col | high-motion + identity rows × widths |
| `perframe_psnr.pdf` | 1-col | V=2 per-frame PSNR, chunk bands |
| `perframe_psnr_v4.pdf` | 1-col | supplement: V=4 companion |
| `latent_width.pdf` | 1-col | widening + per-view reference line |
| `interventions.pdf` | 1-col | temporal interventions bar chart |
| `datascale.pdf` | 1-col | bleed / ghosting / PSNR vs training-set size |
| `rate_quality.pdf` | 1-col | 2×2 matrix + additive prediction |
| `view_count.pdf` | 1-col | PSNR + Bleed-W vs V |
| `resolution_scaling.pdf` | 1-col | supplement: 128/256/512 |

Regenerate: `python make_figures_cvpr.py` (needs `pymupdf`, `pillow`,
`matplotlib`; wandb PNG sources `_wandb_*.png` and `../figures/*.pdf` are in
the repo).
